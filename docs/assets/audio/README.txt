파일명: ambient.mp3 (정확히 이 이름이어야 합니다)
권장: 2~5분 길이, 루프 재생되므로 시작과 끝이 자연스럽게 이어지는 곡이 좋습니다.
용량: 3~6MB 내외 권장 (128~192kbps mp3)

무료 상업적 이용 가능한 음원 추천 검색처:
1. YouTube 오디오 보관함 (studio.youtube.com → 오디오 보관함) — 완전 무료, 저작권 걱정 없음
   검색어: "ambient", "meditation", "calm", "zen"
2. Pixabay Music (pixabay.com/music) — 무료, 출처 표시 불필요
   검색어: "ambient temple", "meditation drone", "singing bowl"
3. Free Music Archive (freemusicarchive.org) — 라이선스(CC BY 등) 꼭 확인
4. Envato Elements / AudioJungle — 유료지만 고품질, 상업 라이선스 명확

추천 분위기: 저음 드론 + 은은한 싱잉볼/바람 소리 계열 (사이트가 이미 이런 느낌으로 세팅되어 있음)
